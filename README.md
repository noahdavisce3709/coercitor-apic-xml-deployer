## What Coercitor Does

Coercitor is a web application for producing XML and delivering it as part of network engineering workflows. It simplifies repetitive ACI configuration work by providing a browser-based process for assembling XML intended for bulk operations.

Generated XML can be attached to APIC or transmitted through a proxy server, depending on how your environment handles deployment. The result is a more direct way to manage recurring configuration preparation and delivery tasks from a single web interface.

---

## Capabilities

- Creates XML files for bulk configuration activities
- Lets users attach generated XML output to APIC
- Supports sending XML through a proxy server
- Focuses on ACI-related network operations
- Fits repeated, everyday configuration workflows
- Runs through a browser-based interface
- Brings XML creation and deployment steps together in one workflow

## Settings and Deployment Configuration

Because Coercitor runs in the browser, its operational settings are generally managed within the application and the current browser session.

When APIC connection information or proxy access is needed, enter those values through the application's configuration or deployment settings. Avoid embedding them directly into the workflow.

## Requirements

To use Coercitor, you need:

- A current web browser
- Access to the ACI environment or APIC when attaching XML there
- Access to a proxy server when using proxy-based deployment
